      Attacking with Burp Suite (or another proxy)
      
    
        
  1. Start Burp Suite, open Proxy, then Open browser (Burp's own browser already trusts Burp). Or point your browser at Burp's listener (127.0.0.1:8080) and install Burp's certificate.
    2. 
        
  2. Press Copy link for Burp above and paste the link into that browser's address bar within a minute. It works once; it signs your browser into your instance.
    3. 
        
  3. Browse the shop. Every request and answer shows up in HTTP history: send them to Repeater, change an order number, a field or a header, and watch what the server lets you do.
    4. 
        
  4. Each challenge below says how to begin (for example which demo account to sign in with) and has three hints that you can reveal one by one.
    5. 
        
  5. When you find a flag (VM{...}) paste it into its challenge. Reset gives you a fresh shop and new flags; the old ones stop counting.
    6. 
      

      
Only attack your own instance. It is built to be broken; nothing else is.
