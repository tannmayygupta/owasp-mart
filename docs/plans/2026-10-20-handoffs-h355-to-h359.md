## 3. H-356 Candidates can start an assessment (story 9, OI-22)
- Decide OI-22: a **Start button** (the candidate presses Start after consent; the clock starts when the instance is ready, D-80). Recorded in the story and the contract text.
- Implement `startAttempt` (`POST /api/v1/attempts/{attempt_id}/start`) in `lab/api.py`: the owner of a candidate attempt in state `ready`; asks the orchestrator for its instance through the runtime (new `start_existing`), answers 202 with the attempt, idempotent while the start is under way, 409 when the state does not allow it, 404 for anyone else. A learner attempt answers 409 (learners use `requestInstance`).
